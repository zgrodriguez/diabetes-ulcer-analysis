# Diabetes Ulcer Analysis

## Descripción del proyecto

Diabetes Ulcer Analysis es un proyecto de aplicación web orientado al análisis y procesamiento de imágenes de lesiones de pie diabético.

Su objetivo es facilitar el procesamiento visual de imágenes mediante técnicas de visión por computadora, permitiendo identificar y analizar regiones de interés.

## Tecnologías utilizadas

- **Backend:** Python y FastAPI.
- **Frontend:** React y TypeScript.
- **Base de datos:** MySQL y SQLAlchemy.
- **Procesamiento de imágenes:** OpenCV y Pillow.
- **Entorno de ejecución:** Docker Compose.

## Funcionalidades principales

- Carga y procesamiento de imágenes.
- Selección manual de regiones de interés (ROI).
- Aplicación de técnicas de umbralización de Otsu.
- Detección de bordes mediante diferentes métodos de procesamiento.
- Visualización de resultados del procesamiento.
